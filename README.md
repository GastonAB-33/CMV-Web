# CMV-Web

Proyecto estatico preparado para ejecutarse localmente en el puerto `5175`.

## Ejecutar

```powershell
npm run dev
```

Luego abre:

```text
http://localhost:5175
```

## Notas

- El servidor esta fijado en el puerto `5175`.
- `npm run dev` y `npm start` usan la misma configuracion.
- El servidor sirve `index.html` en la raiz y tambien como fallback para rutas no encontradas.
